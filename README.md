# VYROX BTC/USD Trading Demo

A responsive React prototype for VYROX with simulated trading only.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run: `npm install`
3. Run: `npm run dev`
4. Open the local URL shown by Vite.

## Deploy free with Cloudflare Pages
1. Upload this project to a GitHub repository.
2. In Cloudflare Pages, connect the GitHub repository.
3. Build command: `npm run build`
4. Build output directory: `dist`
5. Deploy. Cloudflare will provide a `*.pages.dev` URL.

No backend/auth is connected yet. This is a frontend demo with simulated trades and a TradingView embedded chart. No real funds, custody, or exchange orders are involved.
